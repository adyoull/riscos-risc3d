# RISC3D 0.18

A fix for Configure's RISC3D page. Everything else is as in 0.17.

## What's in it

**RISC3D-0.09-2.zip** is also the PackMan package RISC3D. It holds:
- `!RISC3D`, for `!Boot.Resources`, unchanged from 0.17:
  - the RISC3D module 0.09;
  - in `GPU`: Linux3D 0.06 and V3DRender 0.26.
- `!RISC3DSetup` **1.06**, for `!Boot.Resources.Configure`.

## Changes

- **!RISC3DSetup 1.06.** The page is a GCCSDK (UnixLib) program, so it needs the SharedUnixLibrary and ARMEABISupport modules.
  - **Before:** where ARMEABISupport wasn't loaded, opening the page stopped at once with "SWI &59D01 not known" (reported on a CM4).
  - **Now:** its `!Run` loads both from `System:Modules`, or says which to install with PackMan.
